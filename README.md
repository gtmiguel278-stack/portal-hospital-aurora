# Portal Hospital Aurora

Protótipo inicial do Portal Hospital Aurora Capital | North.

## Funcionalidades visuais incluídas
- Tela inicial dos hospitais Capital e North
- Entrada preparada para Login com Discord
- Painel do colaborador
- Hospital do funcionário
- Cargo do funcionário
- Meta semanal de 15 horas
- Barra de progresso
- Status da meta
- Página de horas
- Layout responsivo para computador e celular

## IMPORTANTE
Este primeiro arquivo é o FRONT-END do portal.

A sincronização real com Discord/Nyox ainda precisa de uma etapa de BACK-END, pois um site estático no GitHub Pages não consegue consultar com segurança os cargos dos membros de um servidor Discord sozinho.

Próxima etapa recomendada:
1. Criar uma aplicação no Discord Developer Portal
2. Configurar Discord OAuth2
3. Criar backend/API
4. Conectar ao banco de dados
5. Integrar horas com Nyox, caso o Nyox tenha API ou outra forma de acesso
